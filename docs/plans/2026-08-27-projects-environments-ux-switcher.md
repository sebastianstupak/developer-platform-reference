# Projects & Environments UX + Global Switcher — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a persistent app-bar project/environment switcher, a card-grid Projects list, a new Project Overview page, and a reworked Environment-secrets page, backed by three additive backend query enrichments — plus two structural moves.

**Architecture:** Blazor Server (globally interactive) + MudBlazor v9 zinc theme talking to a Clean-Architecture .NET 10 API over CQRS dispatchers. A per-circuit `ActiveContextService` holds the active project/environment; **the route is the source of truth** — pages push their project/env into the context on load, and the switcher only navigates. Backend changes are additive fields on existing query summaries/DTOs plus one optional audit filter.

**Tech Stack:** .NET 10, EF Core 10 (Pomelo/MariaDB, InMemory for tests), MudBlazor 9.9.0, xUnit, Playwright (`@playwright/test`).

## Global Constraints

- **Commits are slow and hook-gated.** A lefthook `pre-commit` runs arch-tests + full-solution build + `dotnet format` (~90s total). Let it finish; **never** use `--no-verify`. The `commit-msg` hook **rejects AI co-author trailers** — do not add `Co-Authored-By`/`Claude-Session` trailers to commits in this repo.
- **CQRS conventions:** queries are `record … : IQuery<T>` (with `[RequiresPermission(...)]`, optional `IResourceScoped`); handlers are `IQueryHandler<TQuery,TResult>` in `DeveloperPlatform.Infrastructure`, taking `ApplicationDbContext db` via primary constructor.
- **Blazor is globally interactive** via `<Routes @rendermode="InteractiveServer" />` in `App.razor` — do NOT add per-component `@rendermode`.
- **Theme:** MudBlazor v9 zinc theme `DevPlatformTheme.Instance`; borders `LinesDefault` #e4e4e7, radius 0.5rem, Inter font. Reuse it; do not introduce new palettes.
- **Additive DTO changes only.** New fields append to positional records. `AuditFilter` and `AuditFilterDto` gain `Guid? ProjectId = null` **as an optional trailing parameter** so existing 6-arg call sites keep compiling.
- **Route-as-source-of-truth:** the switcher calls `NavigationManager.NavigateTo(...)`; destination pages call `ActiveContextService.SetProject/SetEnvironment`. The switcher never mutates page data.
- **Test harnesses:** backend uses in-memory `ApplicationDbContext` (`new ApplicationDbContext(options, ctx, TenancyMode.SharedTables)` with a `TestExecutionContext`); Web uses `MockHttpMessageHandler`/`CapturingHandler` around `DeveloperPlatformApiClient`; e2e uses `@playwright/test` in `tests/e2e/`.
- **Env-type chip colors:** Production → `Color.Error`, Staging → `Color.Warning`, Development → `Color.Default`.
- **Relative-time format:** `<60s` → "just now"; `<60m` → "Nm ago"; `<24h` → "Nh ago"; `<30d` → "Nd ago"; `<365d` → "Nmo ago"; else "Ny ago".

```csharp
namespace DeveloperPlatform.Web.Components.Shared;

public static class TimeFormat
{
    public static string Relative(DateTime utc) => Relative(utc, DateTime.UtcNow);

    public static string Relative(DateTime utc, DateTime now)
    {
        var span = now - utc;
        if (span < TimeSpan.Zero)
        {
            span = TimeSpan.Zero;
        }

        if (span.TotalSeconds < 60)
        {
            return "just now";
        }

        if (span.TotalMinutes < 60)
        {
            return $"{(int)span.TotalMinutes}m ago";
        }

        if (span.TotalHours < 24)
        {
            return $"{(int)span.TotalHours}h ago";
        }

        if (span.TotalDays < 30)
        {
            return $"{(int)span.TotalDays}d ago";
        }

        if (span.TotalDays < 365)
        {
            return $"{(int)(span.TotalDays / 30)}mo ago";
        }

        return $"{(int)(span.TotalDays / 365)}y ago";
    }
}
```

```csharp
namespace DeveloperPlatform.Web.State;

public readonly record struct ActiveProjectRef(Guid Id, string Name);

public readonly record struct ActiveEnvironmentRef(Guid Id, string Name, string Type);

// Per-circuit holder for the active project/environment. The route is the source of
// truth: pages call SetProject/SetEnvironment on load; the switcher only navigates.
public sealed class ActiveContextService
{
    public ActiveProjectRef? Project { get; private set; }
    public ActiveEnvironmentRef? Environment { get; private set; }

    public event Action? OnChange;

    public void SetProject(ActiveProjectRef? project)
    {
        if (project?.Id != Project?.Id)
        {
            Environment = null;
        }

        Project = project;
        OnChange?.Invoke();
    }

    public void SetEnvironment(ActiveEnvironmentRef? environment)
    {
        Environment = environment;
        OnChange?.Invoke();
    }

    public void Clear()
    {
        Project = null;
        Environment = null;
        OnChange?.Invoke();
    }
}
```

```razor
    private IReadOnlyList<ProjectDto> _projects = [];
    private IReadOnlyList<EnvironmentDto> _environments = [];
    private ProjectDto? _selectedProject;
    private EnvironmentDto? _selectedEnvironment;

    protected override async Task OnInitializedAsync()
    {
        Context.OnChange += OnContextChanged;
        _projects = await ApiClient.GetProjectsAsync();
        await SyncFromContextAsync();
    }

    // Route-as-source-of-truth: when a page pushes a new project/env into the context,
    // reflect it in the switcher labels.
    private async void OnContextChanged()
    {
        await InvokeAsync(async () =>
        {
            await SyncFromContextAsync();
            StateHasChanged();
        });
    }

    private async Task SyncFromContextAsync()
    {
        var projectId = Context.Project?.Id;
        _selectedProject = projectId is null ? null : _projects.FirstOrDefault(p => p.Id == projectId);

        if (_selectedProject is not null)
        {
            _environments = await ApiClient.GetEnvironmentsAsync(_selectedProject.Id);
            var envId = Context.Environment?.Id;
            _selectedEnvironment = envId is null ? null : _environments.FirstOrDefault(e => e.Id == envId);
        }
        else
        {
            _environments = [];
            _selectedEnvironment = null;
        }
    }

    private Task<IEnumerable<ProjectDto>> SearchProjects(string? value, CancellationToken ct)
    {
        var query = string.IsNullOrWhiteSpace(value)
            ? _projects
            : _projects.Where(p => p.Name.Contains(value, StringComparison.OrdinalIgnoreCase));
        return Task.FromResult<IEnumerable<ProjectDto>>(query);
    }

    private Task<IEnumerable<EnvironmentDto>> SearchEnvironments(string? value, CancellationToken ct)
    {
        var query = string.IsNullOrWhiteSpace(value)
            ? _environments
            : _environments.Where(e => e.Name.Contains(value, StringComparison.OrdinalIgnoreCase));
        return Task.FromResult<IEnumerable<EnvironmentDto>>(query);
    }

    private void OnProjectChanged(ProjectDto? project)
    {
        if (project is null || project.Id == _selectedProject?.Id)
        {
            return;
        }

        Context.SetProject(new ActiveProjectRef(project.Id, project.Name));
        Navigation.NavigateTo($"/projects/{project.Id}");

    private void OnEnvironmentChanged(EnvironmentDto? env)
    {
        if (env is null || _selectedProject is null || env.Id == _selectedEnvironment?.Id)
        {
            return;
        }

        Navigation.NavigateTo($"/projects/{_selectedProject.Id}/environments/{env.Id}");
    }

    public void Dispose() => Context.OnChange -= OnContextChanged;
}
```
